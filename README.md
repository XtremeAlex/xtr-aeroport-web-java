# xtr-aeroport-web-java

Frontend web della suite Aeroport: interfaccia per consultare aeroporti e rotte
esposti dai microservizi backend.

## Info sul progetto

Fa parte della suite `xtr-aeroport-*`, un esempio di architettura a microservizi.
Questo modulo e il livello di presentazione web che consuma le API dei servizi
backend.

> Progetto in fase iniziale. La struttura e i dettagli tecnici saranno aggiunti
> con lo sviluppo.

## Suite Aeroport

- `xtr-aeroport-ms` — microservizio di ricerca aeroporti (API REST)
- `xtr-aeroport-batch` — import massivo dati (Spring Batch + GraalVM native)
- `xtr-aeroport-typological` — servizio dati tipologici
- `xtr-aeroport-common-lib` — libreria condivisa
- `xtr-aeroport-web-java` — questo modulo: frontend web
